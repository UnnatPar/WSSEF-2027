# NeutrinoJEPA

Three experiments isolating the effect of self-supervised pre-training objective
on a Point-Edge Transformer (PET) encoder for IceCube neutrino direction
reconstruction and track/cascade classification:

1. **NeutrinoPET**: PET encoder pre-trained via MAE, then probed, then fine-tuned.
2. **NeutrinoJEPAPET**: PET encoder pre-trained via JEPA, then probed, then fine-tuned.
3. **PET+heads**: encoder and heads trained together from scratch (baseline).

See `neutrinojepa_spec.md` for the design spec and
`docs/superpowers/plans/2026-07-10-neutrinojepa-implementation.md` for the
implementation steps.

## Setup

    bash scripts/download_data.sh   # requires Kaggle API credentials
    pip install -r requirements.txt
    # then install torch + PyG extensions per the header of requirements.txt

## Run locally

    # Experiment 1: NeutrinoPET (MAE pre-training)
    python train/pretrain_mae.py --config configs/pretrain_mae.yaml
    python train/probe.py --config configs/probe.yaml
    python train/finetune.py --config configs/finetune.yaml

    # Experiment 2: NeutrinoJEPAPET (JEPA pre-training)
    python train/pretrain.py --config configs/pretrain.yaml
    python train/probe.py --config configs/probe.yaml
    python train/finetune.py --config configs/finetune.yaml

    # Experiment 3: PET+heads from scratch
    python train/finetune.py --config configs/scratch.yaml

## Run on Colab

Open `colab_train_neutrinojepa.ipynb` (generated by `scripts/make_colab_notebook.py`)
in Colab. It installs dependencies, clones this repo, downloads the Kaggle
data, and runs all 3 experiments end to end via the scripts above — the
notebook itself contains no training logic, only orchestration.
